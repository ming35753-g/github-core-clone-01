A GitHub-compatible git forge in a single Node.js process with no dependencies: git smart HTTP (protocol v0 and v2, shallow fetch and deepen, fast-forward push with sideband reports), REST v3, GraphQL, and MCP tools, over one deterministic in-memory store. No git binary, no network beyond the suite, no wall clock or randomness in anything it sends.

## Run it

```sh
node --experimental-strip-types main.ts
```
